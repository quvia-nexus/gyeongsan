1 주제 선정

공모전의 5개 주제 중 하나를 선택하고, 나만의 이야기로 구체화하세요.

생각해 보기: 누구에게 어떤 문제가 있고, AI가 무엇을 바꿀 수 있을까요?

2 핵심 메시지

관객이 영상을 본 뒤 기억했으면 하는 내용을 한 문장으로 작성하세요.

3 스토리 구성

영상의 시작부터 끝까지 4단계로 나누어 큰 흐름을 만듭니다.

① 시작

관심 끌기·상황 소개

② 전개

문제 또는 사건 발생

③ 절정

AI의 활약·변화

④ 마무리

결과·핵심 메시지

4 AI 스토리보드 프롬프트 만들기

1~3단계 내용을 바탕으로 AI가 8초 단위 스토리보드를 작성하도록 요청하는 프롬프트를 만듭니다.

프롬프트 작성 공식: 누가/무엇이 + 어디서 + 어떤 행동 + 화면 구도 + 분위기·조명 + 스타일 + 화면 비율. 영상 프롬프트에는 움직임, 카메라 이동, 변화, 8초를 추가하세요.
아래 완성된 프롬프트를 복사하여 ChatGPT 등 AI에 붙여넣으세요. AI가 전체 스토리보드를 작성합니다.

5 실제 영상 만드는 순서

  1. AI 스토리보드 생성 — 4단계에서 만든 프롬프트를 AI에 입력하고, 생성된 장면별 계획을 검토합니다.
  2. AI 이미지 생성 — 각 장면의 이미지 프롬프트로 한 장씩 만들고, 캐릭터와 배경 스타일을 일관되게 맞춥니다.
  3. 이미지 기반 AI 영상 생성 — 만든 이미지를 영상 생성 도구에 넣고 장면별 영상 프롬프트를 사용해 각 8초 클립을 만듭니다.
  4. 모든 장면 준비 — 장면 순서대로 파일명을 정리합니다. 예: 01_시작.mp4, 02_문제.mp4
  5. 캡컷(CapCut) 편집 — 모든 클립을 순서대로 배치하고 자막, 나레이션, 효과음, 배경음악, 장면 전환을 추가합니다.
  6. 최종 확인 및 출력 — 60~90초인지 확인하고 MP4(H.264), 4K 이하로 내보냅니다. 사용한 음악·이미지·음성의 이용 조건도 확인합니다.
8초 클립만 사용하는 경우 8~11장면(64~88초)으로 구성할 수 있습니다. 도구에서 8초 생성이 지원되지 않으면 생성 가능한 길이로 만든 뒤 캡컷에서 8초에 맞게 편집하세요.
